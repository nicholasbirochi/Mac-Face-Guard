## ArcFace (InsightFace)

`glance/Models/ArcFace.mlpackage` foi convertido pelo autor do Glance a partir do pacote `buffalo_s` (`w600k_mbf`) do
[InsightFace](https://github.com/deepinsight/insightface). O código do InsightFace é MIT, mas os modelos pré-treinados
são distribuídos **somente para pesquisa não comercial**. Este fork não alterou nem baixou de novo o modelo; ele veio com o
repositório original. Não use este fork comercialmente sem resolver essa licença.
